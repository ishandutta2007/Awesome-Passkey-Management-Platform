# Awesome-Passkey-Management-Platform

Top Passkey Management Platform Ecosystem

Curated List of SaaS Products & Open-Source GitHub Projects
Focused on Passkeys, WebAuthn, FIDO2, Passwordless Authentication & Enterprise Credential Management
Last updated: September 2026

This repository tracks notable SaaS/hosted platforms and open-source projects for Passkey Management. These tools help organizations and developers implement, deploy, manage, synchronize, secure, and govern passwordless authentication based primarily on FIDO2 and WebAuthn standards.

Examples include Dashlane Business, 1Password Business, Bitwarden Enterprise, HYPR, Auth0 Passkeys, Hanko, Descope, Stytch, Yubico Enterprise, and Keeper Enterprise (the category leaders).

Open-source emphasis: This section is heavily expanded with major active open-source identity, authentication, WebAuthn, FIDO2, passwordless, MFA, and self-hosted credential-management projects. The open-source ecosystem is particularly strong for organizations that want to own their authentication infrastructure rather than depend entirely on proprietary identity providers. Projects such as Keycloak, Hanko, ZITADEL, Authentik, Ory, SuperTokens, Authelia, Logto, and WebAuthn libraries provide important building blocks for self-hosted passkey platforms.

Additional Strong Open-Source Options

WebAuthn libraries: SimpleWebAuthn, Duo Labs WebAuthn, go-webauthn, webauthn-rs, py_webauthn, and other language-specific implementations for building custom passkey registration and authentication flows.

FIDO2 libraries: Libraries for Python, Go, Java, Rust, JavaScript, and other ecosystems that allow developers to integrate hardware security keys and passkeys directly into applications.

Authentication frameworks: Keycloak, Authentik, Hanko, ZITADEL, Ory Kratos, Logto, SuperTokens, and Authelia cover most self-hosted authentication architectures.

Authorization systems: OpenFGA, SpiceDB, Permify, Cerbos, and Ory Keto can provide the authorization layer behind passkey-enabled applications.

Password and credential vaults: Bitwarden Server, Vaultwarden, Passbolt, and related self-hosted vault projects can complement passkey adoption where organizations still need passwords, API keys, secrets, and shared credentials.

MFA infrastructure: privacyIDEA, Authelia, Keycloak, ZITADEL, and Hanko provide building blocks for combining passkeys with TOTP, security keys, recovery mechanisms, and additional authentication factors.

Identity federation: Apereo CAS, LemonLDAP::NG, WSO2 Identity Server, Keycloak, and Janssen can connect modern authentication systems with existing LDAP, Active Directory, SAML, and enterprise identity infrastructure.

Developer authentication stacks: Supabase Auth, Appwrite, PocketBase, Parse Server, SuperTokens, and Logto are useful for teams that want authentication integrated directly into a broader application backend.

Custom passkey infrastructure: Hanko's dedicated Passkey Server is particularly relevant for applications that already have an authentication system but want to add passkey registration, login, credential management, and transaction signing. 
GitHub

Frameworks for building custom systems: Combine Keycloak, Hanko, ZITADEL, Authentik, or Ory Kratos as the core identity layer; use WebAuthn/FIDO2 for passkey registration and authentication; add privacyIDEA or native MFA capabilities for recovery and additional factors; and connect OpenFGA, SpiceDB, Permify, or Cerbos for fine-grained authorization. For a credential-management layer, combine the authentication stack with Bitwarden, Vaultwarden, or Passbolt. Hanko and ZITADEL are particularly notable for modern passkey-oriented authentication, while broader identity stacks provide passkeys as part of a larger IAM architecture.

Disclaimer

This is a community-curated list — it is not exhaustive and does not constitute an endorsement.

Passkey support varies between platforms, browsers, operating systems, authenticators, and enterprise identity providers.

Not every password manager is a full passkey authentication platform, and not every identity platform provides passkey synchronization or credential-vault functionality.

Organizations deploying self-hosted identity infrastructure should carefully review licensing, security architecture, recovery mechanisms, key management, backup procedures, auditing, and protocol compatibility.

Authentication systems are security-critical infrastructure. Production deployments should undergo appropriate security review, monitoring, patch management, and incident-response planning.

Projects described as source-available should not automatically be considered fully open-source; always review the current license before deployment or redistribution.
